# Sabbir Hossain

Data engineer at Bell Canada in Toronto, with a research base from Johns Hopkins and UofT (bioinformatics and computer science, 3.96 major GPA). I build data and backend systems that need to hold up in the real world.

The full story lives at **[sabbir.ca](https://sabbir.ca)**. I rebuilt it as a field notebook, every system I've worked on is written up with the evidence left in: what it is, why it exists, and a "went wrong" note documenting the failure that taught me something. A resume tells you what someone shipped, the failure notes tell you how they think, so I publish both.

Most of this repo graph is private (client work and unpublished research), but some of the public builds:

* **[What Day Is It](https://whatdayisit.ca)**, a site that tells you what today is anywhere in the world, 250 countries and 500+ pages refreshed on a schedule
* **[Resume Foundry](https://foundry.sabbir.ca)**, turns a Markdown resume into DOCX and PDF that screening software can actually read
* **Signal for Good**, a live job board pulling nonprofit tech roles across Canada and the US into one place
* **Mawiza** and **Hone**, two native iOS apps in progress (Expo, React Native)

The habit underneath all of it: the failures that scare me are the quiet ones, nothing crashes but the numbers underneath are wrong. So most of what I build is about making that class of problem visible before it ships, validation at ingest, row by row reconciliation, lineage you can actually trace.
